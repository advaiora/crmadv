# Handoff di staffetta

Questa cartella contiene i documenti di **staffetta** tra Jacopo (lun-ven) e Claudio (weekend).

- Si lavora uno alla volta e si passa il testimone con un handoff.
- **Leggi sempre per primo il file più recente** (la data/ora è nel nome: `handoff-AAAA-MM-GG-HHmm.md`).
- Vengono tenute **solo le ultime 3 versioni**: alla quarta, la più vecchia viene cancellata automaticamente.

Per generare un nuovo handoff a fine sessione, usa il comando **`/handoff`**.
