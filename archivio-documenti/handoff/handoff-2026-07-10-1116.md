## Come riprendere — prossimi passi

1. **`git pull`** per avere l'ultimo commit.
2. **Allinea il database** applicando le due nuove migrazioni (vedi avviso in cima) e controlla `PLATFORM_ADMIN_EMAILS` nel tuo `.env`.
3. Avvio (**due terminali**): `npm run dev:api` (porta 4000) e `npm run dev` (porta 5173). Login: **admin@test.com / admin123**.
4. **Giro di prova veloce**: (a) Clienti → esporta CSV con un campo personalizzato definito, poi reimportalo; (b) Clienti → scheda "Integrazioni": incolla una chiave Brevo (anche finta), salva, prova "Testa connessione"; (c) apri un progetto Agency → scheda "Fonti" → nel pannello "Fonti indicizzabili per l'AI" aggiungi un URL o del testo, poi rigenera la Discovery e verifica che il contenuto venga usato.
5. **Per continuare la V4**, tre strade possibili (in ordine di comodità):
   - **(a)** caricamento **file Word/PDF** come fonti `ProjectSource` (le librerie di lettura `mammoth` per Word e `pdf-parse` per PDF sono **già usate** lato Agency, quindi il grosso c'è già);
   - **(b)** **sbloccare pgvector** lato server e poi costruire la vettorizzazione/ricerca semantica;
   - **(c)** **multi-provider Claude + controllo costi** nel motore AI (`agency-os`).
6. Quando tocchi lo schema del DB: **sempre `prisma migrate dev`** + committa la migrazione + segnala qui la nuova. Stili: `npm run lint:css` e `npm run lint:colors`. Nota: `npm run dev:api` gira in "watch" e ricarica da solo; se devi rigenerare il client Prisma (`prisma generate`) e dà errore di file bloccato, ferma prima i processi `dev:api`.
